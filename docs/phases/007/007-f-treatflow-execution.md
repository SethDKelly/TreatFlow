## 3. Stale, absent and adverse-state matrix

**Must stay distinguishable:** observed quiet / unwatched / uncertain / no claim; original / amended / contested branch; protected standing active / contested / relinquished / not entitled; research requested / prepared / qualified-with-limits / unsuitable / unavailable / historically delivered; disclosure proposed / approved / restricted / declined / suspended / historically exposed.

**Different denial classes:** (a) target or lifecycle state invalid, (b) claimant/actor entitlement unknown or absent, (c) evidence scientifically unfit or information unavailable, and (d) prospective disclosure risk basis/authority inadequate. Conflating these hides what an actor can legitimately change. A historical result is not a current entitlement and cannot be rewritten by a future action.

**No stale-view guarantee invented:** mappings require *as-of meaning and qualification where consequential*, not real-time synchronization, refresh frequency, notification or disclosure of private changes to otherwise unentitled recipients. If a user-facing design needs a new freshness promise, test it in Phase 005 before adopting it.
