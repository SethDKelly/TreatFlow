# TreatFlow — 008-C False Familiarity, Concept Names & Mental-Model Collision Audit

## Decision

**008-C COMPLETE WITH CARRY-FORWARD — 008-D NEXT ELIGIBLE AFTER MERGE.** After [008-B](008-b-treatflow-execution.md) merged, reviewed all five concept names, their 29 intrinsic action names, [current cross-concept terminology](../../canonical/mapping/integrated-action-language.md), and application state/authority consequences. **No concept-wide rename or semantic refactoring is justified by existing evidence.** A narrow clarification was placed into the existing canonical [integrated language owner](../../canonical/mapping/integrated-action-language.md) because technical names such as `Recognize`, `Qualify`, `Provide`, `Decide` and `SuspendFuture` could otherwise be interpreted as broader user promises.

Comparison uses [008-B evidence classes](008-b-treatflow-execution.md): documented source semantics (E1), partial precedent (E2), hypothetical familiarity expectations (E3), and missing empirical user-transfer evidence (E4). **There is no E4 evidence.** This is a falsification of linguistic implications against current concept authority, not a finding about how actual users understand proposed labels.

## 1. Collision and decision matrix

| Name / likely shorthand | Incorrect inferred promise | Authoritative meaning / disposition |
|---|---|---|
| **Observation / logged event** | Passive, continuous tracking of all activity; omitted period means zero | [Observation](../../canonical/concepts/observation.md): bounded assertions of observed, not observed or uncertain coverage; group/person units and recalled precision explicit. **Retain concept name; qualify reports** |
| **`Close` / complete** | Facts confirmed, data published, correction irrevocably barred | Observation closes **direct additions only**; qualified independent Revision may remain available. **Retain action; prohibit final-truth label** |
| **Contribution Stewardship / owner, author** | Verified public identity; unilateral edit, release, delete and another household member's rights | [Stewardship](../../canonical/concepts/contribution-stewardship.md): protected Party–Item responsibility standing, potentially contested or relinquished. **Retain concept; reject “owner” synonym** |
| **`Recognize` / verified** | Identity independently authenticated and responsibility conclusively accepted | Returns entitled standing and contest state, not identity verification. **Clarify canonical linguistic mapping** |
| **Revision / edit** | Destructive replacement and guaranteed latest correct version | [Revision](../../canonical/concepts/revision.md): successor lineage, historical original, possible forks/challenges. **Retain concept; reject overwrite shorthand** |
| **`Challenge` / correction** | Challenge directly creates replacement assertion or permission to amend | Challenges an Assertion's factual standing only. **Keep distinct from `Amend`** |
| **`ResolveChallenge` / final truth** | Resolver creates replacement fact, chooses every fork, or approves publication | Disposes of factual challenge within its guard; no automatic amendment, authority transfer or downstream release. **Qualify result** |
| **Research Provision / export** | Raw downloadable dataset must exist | [Research Provision](../../canonical/concepts/research-provision.md): inquiry fitness can be limited/unsuitable/unavailable with no delivery. **Retain concept; avoid “data export” substitution** |
| **`QualifyProvision` / certified** | Statistically valid or representative proof, confirmed Poisson process | Known units, exposure, missingness, selection and historical-standing limitations; may report insufficiency. **Reject certification label** |
| **`Provide` / readily available** | Research requester may directly download protected source information | Guarded participant in D-02, no standalone public access. **Clarify action-specific mapping** |
| **Controlled Disclosure / consent** | A reporter's submission gives permission for everyone or guarantees anonymity | [Disclosure](../../canonical/concepts/controlled-disclosure.md): independently authorized material/audience future-availability decision; real consent and safety are unresolved. **Retain name; reject blanket consent synonym** |
| **`Decide` / publish** | Approved decision means distribution occurred | Approval/restriction/decline conditions distinct from historical `MakeAvailable`/ExposureRecord. **Clarify canonical linguistic mapping** |
| **`SuspendFuture` / revoke, erase** | All previously delivered copies disappear or recipients are notified | Stops *future* availability under a decision; previous exposure remains. **Reject retroactive “delete/revoke” implication** |
| **`Inspect`, `InspectHistory`, `InspectProvision`, `InspectDecision` / public view** | All viewers may read raw or protected underlying records | Each is scoped to independently entitled actor/material. **Reject universal “view all”** |
| **Current / latest / final** | Any newest timestamp gives one uncontested truth | Contested Revision forks, research as-of standing, prospective D decision and closed O are distinct. **Qualify contextual currentness** |
| **Anonymous / safe** | Pseudonym or coarse geography guarantees no household linkage | Privacy and linkability safety not established; no general safe-release promise. **Reject safety guarantee** |

These terms are **technical/conceptual names**, not approved interface copy. No fabricated user-testing finding or glossary rewrite has been adopted.

## 2. Distinct concept expectations and evidence verdicts

- **Observation** matches part of ordinary reporting/monitoring vocabulary, but its coverage claims are not passive instrumentation. **Keep distinct** from a generic log.
- **Stewardship** deliberately limits responsibility to protected standing. “Ownership” is a *misleading candidate label*, not a true identity of concepts. **Keep protected standing**.
- **Revision** benefits from familiar version lineage but adds authorized factual challenge and contested-currentness. **Keep non-destructive correction semantics**.
- **Research Provision** overlaps quality evaluation vocabulary; equating it to export would destroy meaningful no-delivery judgments. **Keep suitability-first behavior**.
- **Controlled Disclosure** overlaps access/usage policy terms but adds independent risk-sensitive material/audience decisions and history. **Keep prospective-availability behavior**.

No comparison provides evidence that renaming to a familiar substitute would preserve purpose, action set, authority and composition **and** improve user understanding. This is a **negative substitution decision**, not a universal novelty claim. Further genericity comparison remains 008-D's responsibility.

## 3. Mapping-level precision correction

The [integrated terminology authority](../../canonical/mapping/integrated-action-language.md) gains a compact **008-C clarifying section**: names of protected/internal actions do not promise availability, “recognition” is not identity verification, “qualification” is not scientific certification, “decision” is not distribution, “provision” is not a public download, and prospective suspension is not a past-copy recall. Existing concept specifications and Phase 005 composition already contain these guards; clarification changes only *presentation implications* rather than action behavior.

**No mass renaming:** replacing concepts or action identifiers would have downstream impact on 29-action coverage, C/D composition and maps without supported value. Any later substantive rename requires explicit Phase 003/004 review if identity/behavior changes and correction of Phase 005–007 canonical references.

No confirmed missing intrinsic state, application action, new in-scope product family, or protected-authority rule was demonstrated by the naming audit. **No immediate upstream reopening.**
